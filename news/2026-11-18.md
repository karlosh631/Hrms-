## 1. Microsoft announces Windows Server 2028 with hardened security

### Overview

Microsoft has unveiled Windows Server 2028, its next major server operating system release.
The announcement took place at Microsoft's Ignite 2026 conference on Tuesday.
Windows Server 2028 focuses heavily on default security hardening and modern server management.
The operating system ships with a hardened Server Core configuration enabled by default.
It introduces a flexible security baseline allowing administrators to relax specific settings.
Storage improvements include native NVMe enabled by default and ReFS boot capabilities.
Built-in AI accelerators support local inference models such as Llama.cpp and vLLM.
IT administrators can now preview the release through Microsoft's Insider and TAP programs.

### What happened

Microsoft announced Windows Server 2028 during its Ignite 2026 conference on Tuesday.
Neil Hinnant, Director of Windows Server & I/O Fabrics PM, presented the release details.
Hinnant stated that default hardening reduces the work of establishing secure baselines from day one.
Trusted Launch extends security features to virtual machines to guarantee boot integrity across VM fleets.
The release introduces Confidential VM support to enable integrity-protected runtimes on supported CVM hardware.
Intune management now extends endpoint-management workflows to eligible, persistent servers.
Intune support brings server configuration, compliance, applications, and updates under unified workflows.
Performance improves through native NVMe storage enabled by default on initial installation.
The release adds support for NVMe over TCP and RDMA transport protocols.
Administrators gain the ability to boot server installations directly from ReFS volumes.
New AI accelerators allow administrators to deploy and configure local inference environments.
Microsoft opened early registration via the Windows Insider Program and Technology Adoption Program.

### Why it matters

Establishing a secure server baseline typically requires manual configuration work from IT staff.
By hardening Server Core out of the box, Microsoft reduces early deployment vulnerability windows.
Trusted Launch ensures boot integrity across an organization's entire virtual machine infrastructure.
Confidential VM support provides a path toward hardware-backed runtime integrity for sensitive enterprise workloads.
Bringing Intune management to server fleets simplifies operations by standardizing workflows across endpoints.
Default native NVMe drivers maximize modern storage performance without requiring post-install setup.
NVMe over TCP and RDMA transport capabilities help optimize high-throughput storage networks.
ReFS boot support gives enterprises access to advanced file system resilience on primary drives.
Local AI acceleration enables enterprises to run intelligence workloads directly within local data centers.
Processing AI locally gives organizations greater flexibility over cost structures and infrastructure placement.
Hinnant noted the platform extends Microsoft Foundry to transform local infrastructure into local token factories.
Customers gain more choices for putting intelligence in the right place at the right cost.

### Technical details

Windows Server 2028 activates hundreds of security settings automatically upon initial system boot.
Administrators retain access to a new security baseline that lets them selectively relax settings.
