## 1. Cursor confirms security breach led to malicious Claude Code extension

### Overview
- AI-powered code editor Cursor confirmed a security breach involving a malicious extension.
- The compromise originated from stolen credentials at AI infrastructure provider Fireworks AI.
- Hackers published malicious copies of Anthropic's Claude Code extension on Cursor's marketplace.
- Up to 5,000 developers were exposed to malware designed to plant SSH backdoors.
- The intrusion allowed attackers to compromise internal Cursor systems and steal customer data.
- Cursor has taken remediation steps, including moving traffic away from Fireworks AI.

### What happened
- The attack began when hackers obtained an access key stored on Fireworks AI.
- Fireworks AI serves as a third-party provider for AI model training and inference.
- Attackers used the stolen key to copy data from Cursor's read-only storage bucket.
- This storage bucket was used to share information with Fireworks AI.
- It contained historical AI coding-agent traces collected primarily from 2025.
- The traces came from users who had not enabled Privacy Mode on Cursor.
- These unredacted traces were maintained so data could be used for AI model training.
- Certain exposed traces contained unredacted API credentials belonging to internal Cursor systems.
- Cursor stated that under 0.05% of its users had coding-agent traces exposed.
- Fewer than 0.01% of customers had API credentials compromised in the security breach.
- Hackers leveraged the exposed credentials to steal data from several Cursor SaaS tools.
- Cursor's monitoring systems detected unauthorized activity, triggering an incident response.
- The company revoked the Fireworks access key and rotated all compromised credentials.
- Cursor temporarily shut down selected internal and product services as a safety precaution.
- However, attackers obtained a credential allowing them to distribute extension marketplace builds.
- On October 29, attackers published malicious versions of Anthropic's Claude Code extension.

### Why it matters
- Up to 5,000 developers requesting affected extensions during the window may be compromised.
- The incident highlights the security risks associated with storing unredacted credentials in AI traces.
- Background: AI coding assistants process high volumes of sensitive developer interactions and API keys.
- Background: Compromised developer workstations can serve as entry points into wider corporate networks.
- Cursor confirmed that Privacy Mode users were completely safe from trace data exposure.
- Official application releases and customer code repositories were not compromised.
- Cursor's core production infrastructure was also unaffected by the initial bucket leak.
- Customers who installed affected extension versions must perform immediate manual remediation.
- The attack underscores how third-party AI supply chain vendors can introduce critical risks.
- Unsanitized telemetry data exposed sensitive keys, enabling broader downstream operational access.
