## 1. Google patches eighth Chrome zero-day exploited in attacks this year

### Overview
- Google has issued emergency security updates for the Chrome web browser.
- The update patches a newly discovered high-severity zero-day vulnerability.
- This security issue is actively exploited in zero-day cyberattacks.
- It represents the eighth Chrome zero-day flaw addressed this year.
- Google released the official security advisory on a Monday.
- Fixed builds are now rolling out to desktop users globally.
- Users can update manually or rely on Chrome's automated update system.
- The flaw specifically targets the browser's XML processing component.
- Background: Major browser vendors regularly publish emergency patches to address zero-day threats.
- Background: Web browsers are critical software components exposed to external web content.
- Background: Use-after-free bugs are frequent targets for memory corruption exploitation.

### What happened
- Google officially acknowledged an active exploit for CVE-2026-125350 in the wild.
- The company published details in a Monday security advisory.
- Fixes have been released for Chrome on Windows, macOS, and Linux.
- macOS users receive patched versions 157.0.8103.50 or 157.0.8103.51.
- Linux desktop installations are updated to version 157.0.8103.50.
- Windows versions are also receiving the emergency desktop release.
- BleepingComputer confirmed the patch was available immediately during testing.
- Chrome will automatically download and install updates upon restarting.
- Manual checks can be triggered within the browser's settings menu.
- Background: Google distributes browser patches through its Stable Desktop channel.
- Background: Staggered software rollouts ensure update stability before reaching all global installations.

### Why it matters
- Attackers are actively abusing CVE-2026-125350 in real-world exploit campaigns.
- This vulnerability is the eighth zero-day patched in Chrome since the year began.
- Google addressed seven other actively exploited Chrome zero-days earlier this year.
- Unpatched installations leave desktop users susceptible to execution of malicious code.
- Google warned that update deployment to all users may take days or weeks.
- Rapid patching is required to protect systems before exploit details leak.
- Memory layout manipulation allows attackers to gain unauthorized access.
- Background: Zero-day vulnerabilities pose high risks because security defenses lack prior signatures.
- Background: Exploitation of web browsers can give attackers entry into host operating systems.
- Background: Fast patch application is essential for maintaining corporate cybersecurity hygiene.

### Technical details
- CVE-2026-125350 is categorized as a Use-After-Free (UAF) memory flaw.
- The vulnerability exists within Google Chrome's XML component.
- The error occurs when the browser's XML parser processes data.
- The parser deletes a specific object from computer memory during processing.
- The parser fails to clear the pointer referencing the deleted object.
- A high-severity memory corruption vulnerability is created by this uncleared pointer.
- Attackers exploit the flaw when the browser attempts to access freed memory.
- Attackers can manipulate the layout of memory space to execute code.
- Successful exploitation allows arbitrary malicious code execution inside the browser context.
- Background: Use-After-Free vulnerabilities are common memory safety issues in C++ software.
- Background: Memory pointers referencing freed space allow attackers to manipulate execution control.

### Industry impact
- Google is withholding detailed technical bug descriptions for security reasons.
- Access to bug details and links remains restricted to protect users.
- Restrictions will persist until a majority of active users update.
- Restrictions also remain if third-party libraries share the underlying defect.
- Other software projects relying on the affected XML library could be affected.
- In 2025, Google fixed eight Chrome zero-days exploited in wild attacks.
- Many 2025 exploits were identified by Google's Threat Analysis Group (TAG).
- Google TAG specifically tracks zero-day exploits utilized in spyware attacks.
- Background: Shared open-source components can spread zero-day vulnerabilities across multiple applications.
- Background: Commercial spyware vendors often target zero-day flaws in mainstream browser software.

### What to watch next
- Google has not yet shared specific attack incident details publicly.
- It is currently unknown which specific threat actors are exploiting the flaw.
- The precise identities of target victims remain unconfirmed in official reports.

## 3. Fervo now has $12B in orders for its geothermal power tech

### Overview

Geothermal company Fervo recently released its third-quarter earnings report on Monday.

The company announced it now has $11.9 billion worth of contracted revenue on the books.

This figure has increased significantly from $7.2 billion reported during the previous quarter.

Fervo has successfully been hitting its project deadlines recently to help drive these orders.

### What happened

Hyperscalers are currently scouring the earth to find electricity for their AI data centers.

Fervo is notably on track to complete a 396-megawatt power plant for Google by the end of 2028.

Earlier this year, the geothermal company successfully connected its first 100-megawatt power plant to the grid.

Both of these major projects are built at Cape Station in Utah.

This site could potentially generate 8.4 gigawatts of electricity in total.

Experts previously told Fervo that the same site could only produce about 4 gigawatts.

Co-founder and CEO Tim Latimer discussed the Google project during an earnings call on Monday.

The Google project is now officially called Cape Google 400.

This specific project will be fully grid connected according to the CEO.

Google can draw power from the deal and sell it to other customers if it is not ready to use it.

Latimer stated that they built Cape Station entirely on their own schedule.

Google can develop a potential data center on their own schedule as well.

Neither party has to wait on the other under this flexible arrangement.

### Why it matters

Latimer's statement highlights a key advantage that geothermal has over competing power sources.

Large nuclear or natural gas power plants do not share geothermal's phased construction nature.

Fervo's newer wells are being drilled deeper and hotter than before.

Each of these new wells is capable of generating 15 megawatts of gross power.

Several wells are linked together into what the company calls a GeoBlock.

The first completed GeoBlock generated 33 megawatts of power.

More recent GeoBlocks have successfully hit 50 megawatts.

These blocks are purposely sized to match the demand of a typical data center hall.

Hyperscalers can bring these specific blocks online as they are completed.

### Technical details

As a business, Fervo is still operating in the early stages of its development.

The company ended the quarter with an operating loss of $43.7 million.

Fervo currently holds cash and cash equivalents totaling $1.9 billion.

The company also holds a long-term debt of $301.6 million.

These financial figures should give the firm plenty of operational runway.

The first phase of the Cape Station project cost $7,000 per kilowatt of capacity.

The cost for the upcoming Google project dropped to $5,500 per kilowatt.

This significant cost drop suggests Fervo is on the right path technically and financially.

With subsidies, that cost is about equivalent to a new natural gas power plant running on fuel costing $6 per million BTUs.

That is still about twice what natural gas costs today.

However, the cost is trending closer to where Fervo ultimately needs it to be.

The company's long-term target is to reach $3,000 per kilowatt.

Hitting this ambitious target would allow Fervo to significantly undercut natural gas power, even at today’s prices.

### Industry impact

Much of Fervo's future success will depend on bringing down the cost of its power plants.

Hyperscalers are certainly hungry for power today.

However, these major tech companies may not always remain price-indiscriminate.

If Fervo can successfully deliver on its promises, it could end up winning on price.

The company has made significant strides in just a few short years of operation.

It is no wonder that tech giants like Google are getting in early.

### What to watch next

Background: Fervo's business model relies heavily on scaling geothermal energy for intensive modern computing workloads.

Background: Geothermal energy utilizes heat from the earth's crust to generate electricity continuously.

## 5. Google Gemini routes personal Drive files and emails to human annotators

### Overview
Welcome to today's daily IT news digest for November 10, 2026.
We are reporting on a significant development regarding Google Gemini Workspace extensions.
In 2023, Google initially launched these extensions with a specific promise.
That original guarantee stated that personal content from Gmail, Docs, and Drive would not be seen by human reviewers.

### What happened
Google has now quietly reversed this important commitment.
The reversal was made under updated Google Help Answer 16836988.
It was also confirmed in an October 16 edit to Google's 2023 blog post.
Google now explicitly confirms that connected Drive and email data are routed into human review pipelines.
Clear warnings are now issued by the company regarding this data handling.
Google warns that reviewers may see the actual email or file.
Users are specifically warned not to connect apps to Gemini Apps if they contain confidential information.
This warning applies to data that users would not want a reviewer to see.

### Why it matters
The original 2023 sale of Workspace integration relied on a strict isolation guarantee.
That critical isolation from human review has now been completely removed.
Full files are ingested probabilistically during casual conversation.
These ongoing sessions are now fully subject to human contractor review.
Automatic scrubbers using regex and Named Entity Recognition cannot sufficiently deidentify narrative data.
This failure includes account numbers, confirmation numbers, and transaction dates.
It also affects collectively identifying personal information like name, city, and event combinations.

### Technical details
Testing demonstrates that data ingestion occurs autonomously in background conversations.
This happens without requiring explicit @Drive or @Gmail tags.
The payload capture mechanism operates in a probabilistic manner.
When consumers chat with Gemini with Connected Apps enabled, ambient mentions trigger lookups.
Mentioning trips, bills, names, or reservations autonomously triggers background Workspace lookups.
Because tool-calling and context injection are probabilistic, running a test yields distinct scenarios.
Four distinct scenarios can occur when querying the system.
Scenario one is Zero Retrieval, where no personal data is pulled.
Zero retrieval is likely if Gemini uses model weights or prior history to resolve queries.
Scenario two is Metadata or Generic Summary, pulling high-level summaries.
Scenario three is Partial Unredacted Extraction, pulling 2-4 sentence exact quotations.
Partial extractions frequently include sensitive PII, account details, or specific figures.
Scenario four is Full-File Ingestion, where complete unredacted text is ingested into context.
Testing requires Connected Apps to be active in consumer Gemini settings.
Gemini must be set to "Flash" with "High Thinking" or better.
Users can test this by mentioning a subject in Drive or Gmail without using tags.
An example test query involves asking about paying too much for internet service.
Trials have successfully spit out all four possible outcomes from this single query.

### Industry impact
Users can no longer rely on the privacy guarantees previously advertised for Workspace extensions.
The probabilistic nature of the tool-calling makes behavior difficult to predict.
Background lookups happen without user awareness during ordinary chatting.
Contractors reviewing these sessions gain access to unredacted personal files and emails.
The limitations of automated regex and NER scrubbers are highlighted by this behavior.

### What to watch next
Users must decide whether to disconnect their apps from Gemini Apps.
Individuals must weigh the risk of confidential information being exposed to human reviewers.
It remains to be seen if Google will issue further clarifications on Help Answer 16836988.
Future updates to the Gemini platform may alter these background ingestion behaviors.
Observers will watch for any changes to Google's data handling and human review policies.
