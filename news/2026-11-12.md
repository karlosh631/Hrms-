## 1. AWS distills its cloud into a local emulator that runs on your PC

### Overview
AWS has released a local tool called "AWS Emulator" to run cloud APIs on personal computers.
The emulator acts as a local program that serves an AWS API endpoint directly on a laptop.
Developers can test their applications locally without making network calls to the AWS cloud.
Because API tests never touch the live AWS cloud, using the emulator tool is entirely free.
The utility brings micro-computing and hyperscale cloud development closer together for software engineers.
It supports testing on developer machines, dedicated development servers, and continuous integration pipelines.
The emulator does not replicate the full AWS cloud infrastructure.
Instead, it focuses on offering local endpoints for AWS application programming interfaces.

### What happened
AWS announced the release of its new tool through a dedicated GitHub repository.
The software is prosaically named "AWS Emulator."
